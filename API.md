
| Питання | Що каже документація | Що показав запит (адреса та фактична поведінка) |
| :--- | :--- | :--- |
| **Ендпоїнт пошуку за назвою, параметри** | `GET /search/shows?q=:query`. Шукає серіали за назвою із використанням нечіткого алгоритму. Результати відсортовані за релевантністю. | `https://api.tvmaze.com/search/shows?q=girls` - Повертає 200 OK. Параметр `q` має бути обов'язково закодований через `URLSearchParams`. |
| **Форма відповіді пошуку** | Масив об'єктів. Кожен елемент містить `score` (релевантність) та об'єкт `show` із повною інформацією про серіал. | `https://api.tvmaze.com/search/shows?q=girls` - Структура відповіді: `[ { "score": 0.909, "show": { "id": 139, "name": "Girls", ... } } ]`. |
| **Ендпоїнт серіалу; як отримати епізоди й акторів одним запитом** | `GET /shows/:id`. Для отримання вкладених даних використовується параметр `embed`: `?embed[]=episodes&embed[]=cast`. | `https://api.tvmaze.com/shows/82?embed[]=episodes&embed[]=cast` - Повертає об'єкт серіалу з додатковим полем `_embedded: { episodes: [...], cast: [...] }`. |
| **Поля серіалу, що можуть бути null** | Зображення (`image`), опис (`summary`), оцінка (`rating.average`), мережа (`network`), `webChannel`, `ended`, `officialSite` можуть бути `null`. | `https://api.tvmaze.com/shows/1` - Поле `network` дорівнює `null`. Відсутність зображення також повертає `null` замість об'єкта. |
| **Що повертає пошук без результатів** | Повертає порожній список, якщо жоден серіал не відповідає запиту. | `https://api.tvmaze.com/search/shows?q=qwerty` - Статус 200 OK, тіло відповіді — порожній JSON-масив: `[]`. Це не помилка. |
| **Що повертає неіснуючий id** | Якщо серіал із вказаним ID не знайдено, сервер повертає HTTP-помилку 404. | `https://api.tvmaze.com/shows/999999999` - Статус 404 Not Found, тіло: `{ "name": "Not Found", "message": "", "code": 0, "status": 404 }`. `fetch` не відхиляє проміс. |
| **Ліміт запитів і що робити на 429** | Щонайменше 20 запитів за 10 секунд на IP. При перевищенні - 429 Too Many Requests. Рекомендація: зробити паузу на кілька секунд. | При частому відправленні повертається 429. Код має чекати 2-5 секунд і автоматично повторювати запит (backoff). |
| **Кешування: що кешує TVmaze і що — браузер** | TVmaze кешує відповіді на 60 хвилин. Індекс та розклад кешуються до 24 годин. | `https://api.tvmaze.com/shows/82` - Сервер віддає `Cache-Control: public, max-age=3600`. Браузер при повторі віддає дані з `(disk cache)` без мережі. |
| **CORS: що обіцяє документація і що показав експ. 12** | Усі ендпоїнти мають увімкнений CORS для прямих запитів з вебаплікацій. | `https://api.tvmaze.com/shows/82` - GET без заголовків проходить. Додавання `Content-Type: application/json` викликає CORS error через відхилений OPTIONS preflight. |
| **Ліцензія й атрибуція** | Ліцензія CC BY-SA. Вимагається атрибуція (посилання на TVmaze як джерело). | Всі об'єкти містять `url` та `_links.self.href`. Застосунок повинен давати посилання на TVmaze. |
